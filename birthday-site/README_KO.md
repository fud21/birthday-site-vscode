# 생일 사이트 수정·전달 방법

## VS Code에서 수정하기

1. ZIP을 압축 해제하세요.
2. VS Code에서 `파일 → 폴더 열기`로 `birthday-site` 폴더를 여세요.
3. `birthday-config.js`를 열고 `friend`에는 친구 이름, `sender`에는 보내는 사람, `message`에는 편지를 적으세요.
4. 저장하고 `index.html`을 브라우저로 열어 확인하세요. 이미 열려 있으면 새로고침하세요.

```js
window.BIRTHDAY_GIFT = {
  friend: '친구 이름',
  sender: '내 이름',
  message: `생일 축하해!

여기에 하고 싶은 말을 적어 줘.
엔터로 줄을 바꿔도 돼 ♡`,
};
```

이름은 따옴표 안의 글자만 바꾸세요. 편지는 두 백틱(`) 사이에 적고, 편지 안에 백틱이나 `${...}` 코드를 넣지 마세요. 이름은 최대 20자, 편지는 최대 1,000자가 표시됩니다. 입력창이나 편집 버튼은 친구가 보는 화면에 없습니다.

## 어떤 파일을 바꾸나요?

| 파일 | 역할 |
| --- | --- |
| `birthday-config.js` | 친구 이름, 보내는 사람, 생일 편지 |
| `index.html` | 화면의 기본 문구와 구성 |
| `style.css` | 색상, 크기, 배치, 움직임 스타일 |
| `app.js` | 깨우기, 별 모으기, 촛불 끄기 등 게임 동작과 대사 |
| `assets/` | 캐릭터 그림, 글꼴, 아이콘, 글꼴 라이선스 |

## 친구에게 전달하기

추천 방식은 이 폴더의 **전체 파일과 assets 폴더를 정적 웹 호스팅에 배포하고, 공개 웹주소를 친구에게 보내는 것**입니다. 친구는 휴대폰에서도 링크만 누르면 됩니다. `index.html`이 배포 폴더의 맨 위에 오도록 올리세요.

`index.html` 파일 하나만 보내면 CSS, 게임 코드, 캐릭터 그림이 빠집니다. 파일로 전달하려면 이 ZIP 전체를 보내고, 친구가 압축을 푼 뒤 `index.html`을 열어야 합니다. 휴대폰에서는 공개 링크로 보내는 방식이 간편합니다.

내 PC에서 파일을 수정하는 것과 배포된 웹사이트를 수정하는 것은 별개입니다. 파일을 바꾼 다음에는 수정한 전체 폴더를 다시 배포해야 웹주소에도 반영됩니다. 이 ZIP을 다른 곳에 배포해도 기존 ChatGPT 사이트가 자동으로 변경되지는 않습니다.

이 파일은 별도 설치·빌드 없이 실행되는 HTML/CSS/JavaScript 사이트입니다. 개인별 편지는 소스 파일의 설정만 사용하며 주소의 `#gift=...`나 이전 브라우저 저장값으로 바뀌지 않습니다.
